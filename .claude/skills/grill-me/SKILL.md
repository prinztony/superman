---
name: grill-me
description: A relentless interview to sharpen a plan or design. Use when the user wants to stress-test a plan, idea, or design before building it.
disable-model-invocation: true
---

Interview the user relentlessly about every aspect of their plan or design until you reach a shared understanding.

- If no plan has been given yet, first ask the user to describe it briefly.
- Walk down each branch of the decision tree and resolve dependencies between decisions one by one, starting with the most fundamental ones.
- Ask **exactly one question at a time** and wait for the answer before asking the next.
- For every question, give your own recommended answer and a short reason why.
- If a question can be answered by looking at the codebase, look it up yourself instead of asking.
- Point out gaps, contradictions, risks, and unstated assumptions directly.
- Answer in the user's language.
- When every important branch is resolved, or the user says stop, summarize: the decisions made, open questions, and risks. Offer to save the summary as a file.
